# TaskFlow

TaskFlow is a modern, calming productivity landing page for a fictional task management app. The project presents a polished SaaS-style homepage that highlights the product’s value proposition, features, customer stories, and pricing, all wrapped in a clean and approachable design.

## What this project entails

This project is a front-end website built with plain HTML, CSS, and JavaScript. It is designed to feel like a real product landing page for a task and productivity tool, with:

- A strong hero section and branded messaging
- Feature highlights focused on focus, organization, and collaboration
- Customer testimonial cards
- Pricing plans for different user types
- Responsive layout behavior for smaller screens
- Smooth reveal animations and mobile navigation interaction

## Project structure

- `index.html` – page structure and content
- `index.css` – styling, layout, responsive design, and visual theme
- `index.js` – small interactive behaviors such as mobile menu toggling and scroll reveal animations

## Purpose

The goal of this project is to showcase a premium productivity app experience in a simple static website format. It is useful as a UI mockup, portfolio piece, or starting point for a larger task-management app.

## How to run it

Because this is a static site, you can open it directly in a browser.

1. Navigate to the project folder.
2. Open `index.html` in your browser.
3. If you want to serve it locally, you can also run a lightweight local server in the project directory, for example:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Design style

The interface uses a soft, modern aesthetic with warm neutral colors, accent highlights, and clean typography. The layout is intentionally minimal, emphasizing clarity and focus—matching the product concept of reducing overwhelm and helping users manage tasks more effectively.

## Notes

This is a static front-end demo rather than a full task management application with backend storage or authentication. It demonstrates product marketing and UI design rather than actual app functionality.
